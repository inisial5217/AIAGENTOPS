## 3. Implementasi Detail Fitur Unggulan

### A. Dual Login & Instant Access Demo Profiles (`/login`)
1. **Enterprise SSO (Keycloak OIDC)**:
   - Terintegrasi langsung dengan realm `cifo` dan client `cifo-frontend` di `http://127.0.0.1:8180`.
   - Menggunakan alur Authorization Code / Implicit PKCE standar enterprise.
2. **1-Click Quick Demo Profiles**:
   - 🛡️ **Admin Profile**: `admin` / `admin_password` (Hak akses penuh konfigurasi dan audit).
   - ⚡ **DevOps Profile**: `devops` / `devops_password` (Hak akses remediator, prober, dan scaling).
   - 👁️ **Viewer Profile**: `viewer` / `viewer_password` (Hak akses monitoring read-only telemetri).
   - Mengirim request nyata ke endpoint Go Backend `POST /api/v1/auth/login` dan menyimpan token JWT ke `localStorage`.

### B. Standardized 3-Tier Grid Layout (`/monitoring`)
1. **Tier 1 (Top Row KPI Metrics - 6 Cards)**:
   - `TOTAL KONTAINER`: 145 (Sub: 12 Namespaces)
   - `TOTAL REPLIKA`: 312 (Sub: 4 K3d Clusters, Cyan Accent Top)
   - `OVERALL RAM`: 64% (Sub: 41.2 GB / 64 GB, Amber Accent Top)
   - `KONTAINER ON`: 142 (Sub: 97.9% Operational, Emerald Accent Top)
   - `KONTAINER OFF`: 3 (Sub: CrashLoopBackOff, Pink Accent Top)
   - `ACTIVE INCIDENTS`: 2 (Sub: Requires Remediation, Red Alert Accent Top)
2. **Tier 2 (Middle Row - 2 Large Panels)**:
   - **Host Resource Usage**: Visualisasi telemetri real-time dengan tab switcher (`CPU & RAM`, `Network I/O`, `AI Tokens`), kurva SVG multi-layer dengan gradient fill neon cyan & pink, legend dinamis CPU 48%, RAM 64%, dan NVMe Root 182 GB / 500 GB.
   - **System Event Logs**: Terminal log interaktif bergaya CRT/monokrom dengan tag warna semantik (`[INFO]` cyan, `[CRITICAL]` rose, `[AI-OPS]` emerald, `[WAITING]` amber), auto-scroll lock toggle, dan tombol export teks log.
3. **Tier 3 (Bottom Row - Architecture & Autonomous AI)**:
   - **Agent Architecture & Model Usage**: Menampilkan health check engine microservice: Prober Daemon (`8ms latency`, `1,248 pings/min`), Docker Daemon (`v26.1 API`, `145 Containers`), ArgoCD Controller (`GitOps Synced #f389a1c`), dan Gemini 1.5 Flash (`99.4% Acc`, `Autonomous Level 2`).
   - **AI Autonomous Assistant**: Co-pilot cerdas dengan indikator aktif `• Gemini 1.5 Active`, riwayat percakapan SRE, quick action chips (`⚡ Quick Fix`, `Cek Pods`, `Analisis Node`), serta input prompt interaktif.

### C. Navigasi & Shell Layout
1. **Accordion Hierarchical Sidebar**:
   - Logo CIFO dengan radar pulse radar ring dan tagline `your unlimited it partner`.
   - Collapsible state (lebar 64px saat collapsed, 256px saat expanded).
   - Sub-menu Kubernetes (5 routes): `Cluster Overview`, `Workloads & Pods`, `ArgoCD / GitOps`, `Network & Ingress`, `Chaos Lab`.
   - Sub-menu Docker (4 routes): `Containers`, `Images`, `Volumes`, `Networks`.
   - Menu utama `Monitoring`, `Incidents`, `Settings`, dan tombol `Exit` merah di bagian bawah.
2. **Dynamic Header**:
   - Global Search input dengan shortcut badge `Ctrl + K`.
   - Time range dropdown selector (`Last 1 Hour`, `Last 6 Hours`, dsb.).
   - Tombol `+ Quick Fix` dengan warna cyan glow yang membuka modal aksi remediasi otomatis.
   - Tombol Theme Toggle (Sun/Moon) yang mengubah tema terang/gelap secara instan.
   - Lonceng notifikasi dengan counter badge merah yang menampilkan daftar alert aktif.
   - Avatar profil pengguna dengan inisial nama, badge peran (`ADMIN`, `DEVOPS`, `VIEWER`), dan menu sign out.
