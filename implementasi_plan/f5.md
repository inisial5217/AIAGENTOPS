## 2. Backend Go Layer — Detail Implementasi

### 2.1 Docker Client Integration

#### [NEW] [`apps/backend/internal/integration/docker_client.go`](file:///d:/agent%20v2/apps/backend/internal/integration/docker_client.go)
- **5,912 bytes** — Wrapper klien Docker Engine menggunakan SDK resmi
- Inisialisasi: `client.NewClientWithOpts(client.FromEnv, client.WithAPIVersionNegotiation())`
- Kompatibel lintas platform: Windows named pipe (`//./pipe/docker_engine`) dan Linux Unix socket (`/var/run/docker.sock`)
- Metode yang diimplementasikan:

| Metode | Deskripsi | Docker SDK Call |
|--------|-----------|-----------------|
| `ListContainers(ctx, all)` | Daftar semua kontainer (running/stopped) | `ContainerList` |
| `GetContainer(ctx, id)` | Detail satu kontainer (inspect) | `ContainerInspect` |
| `GetContainerStats(ctx, id)` | Live stats CPU/Memory/Network/IO | `ContainerStats` + stream decode |
| `GetContainerLogs(ctx, id, tail)` | N baris log terakhir | `ContainerLogs` + `StdCopy` |
| `RestartContainer(ctx, id)` | Restart kontainer | `ContainerRestart` |
| `StopContainer(ctx, id)` | Stop kontainer | `ContainerStop` |
| `ListImages(ctx)` | Daftar semua images | `ImageList` |
| `ListVolumes(ctx)` | Daftar semua volumes | `VolumeList` |
| `ListNetworks(ctx)` | Daftar semua networks | `NetworkList` |
| `GetSystemInfo(ctx)` | Info host Docker (CPU, Memory, kernel) | `Info` |

- Error handling: Semua error di-wrap ke `apperror.AppError` untuk konsistensi respons API.

## 9. Catatan Teknis & Known Issues

### 9.1 Keycloak Database Connection Issue
- Keycloak (`cifo-keycloak`) mengalami `java.sql.SQLException: Acquisition timeout`
- **Workaround**: Development mode login bypass (`devLoginFallback`) di `AuthService`
- Token dev: `dev-token-admin` dengan roles `["admin", "devops", "viewer"]`
- Ini hanya untuk development — production akan menggunakan Keycloak OIDC penuh

### 9.2 Docker Containers Response Time
- Response time untuk `/api/v1/docker/containers` bervariasi: 141ms - 902ms
- Ini normal karena Docker Engine perlu menginspeksi setiap kontainer
- Caching Redis (60s) mengurangi beban pada data yang jarang berubah

### 9.3 Next.js Proxy Rewrite
- Proxy rewrite diperlukan untuk menghindari CORS issues saat development
- Production akan menggunakan Nginx/Envoy reverse proxy
